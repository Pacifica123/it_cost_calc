# ПУАЗ — материал по слайдам

> Формат специально сжат. Основные доказательства, оговорки и формулы находятся в `puaz_academic_context.md`.

## Слайд 1. Тема и проблема

**Интерактивная визуализация результатов выбора ИТ-решения**

- диплом уже считает TCO/NPV + GA/AHP/Pareto/Hybrid;
- результат многомерный, статические отчёты плохо показывают связи;
- задача ПУАЗ — **визуально исследовать и обосновать результат**, а не пересчитать его.

**Тезис:** [A] — предмет работы, [E] — точка запуска/экспорта.

---

## Слайд 2. Данные

`DecisionReport` объединяет:

- альтернативы `CandidateConfiguration`;
- CAPEX / OPEX / TCO / NPV;
- технические метрики;
- GA / AHP / Pareto / Hybrid;
- качество данных, warnings, provenance.

**Источник внешних данных пока не фиксируется.** Интернет-магазин + парсинг — только возможный сценарий.

---

## Слайд 3. Цель и задачи

**Цель:** разработать интерактивный дашборд для сравнительного анализа альтернатив.

**Задачи:**

1. выделить показатели;
2. обосновать визуализации;
3. связать графики интерактивностью;
4. сохранить точные данные для проверки;
5. встроить результат в [E] без изменения аналитического ядра.

---

## Слайд 4. Расчётная цепочка

```text
Данные → нормализация → ПО/ТО → CandidateConfiguration
→ GA → AHP → Pareto → Hybrid → TCO/NPV
→ DecisionReport → интерактивный дашборд
```

**Важно:** дашборд не запускает методы заново и не меняет победителя.

---

## Слайд 5. Визуализации

| Представление | Зачем |
|---|---|
| KPI | быстрый обзор |
| TCO × поддержка | компромисс цена/аналитика |
| ранги методов | согласованность GA/AHP/Pareto/Hybrid |
| CAPEX + OPEX | структура затрат |
| качество данных | контроль полноты и warnings |
| таблица | точная проверка значений |

---

## Слайд 6. Интерактивность

- фильтр **Все / ПО / ТО**;
- выбор альтернативы из списка;
- клик по точке на графике;
- tooltip с TCO и поддержкой;
- связанный блок рангов методов;
- адаптивный standalone HTML.

**Интерактивность = переход «обзор → выбранная альтернатива».**

---

## Слайд 7. Диагностический индекс

Разные методы имеют разные шкалы score → напрямую их сравнивать нельзя.

Для визуализации используем только ранги:

```text
S_im = 100 × (n_m - r_im) / (n_m - 1)
S_i = среднее S_im по доступным методам
```

- 1-е место = 100;
- последнее = 0;
- **индекс не участвует в выборе победителя**.

## Слайд 8. Практическая реализация

Новый модуль:

`interactive_dashboard_exporter.py`

Результат:

`data/generated/decision_dashboard.html`

Полный [E] теперь выдаёт:

**JSON + MD + CSV + components CSV + interactive HTML**.

Без CDN и обязательного сервера.

---

## Слайд 9. Что анализируем на демонстрации

1. диапазон TCO;
2. положение победителя на карте альтернатив;
3. совпадение/расхождение методов;
4. различие CAPEX/OPEX;
5. полноту исходных технических данных.

**Итог:** визуализация помогает объяснить *почему* альтернативы отличаются.

---

## Слайд 10. Результат и развитие

**Получено:** программируемый интерактивный аналитический отчёт поверх дипломного `DecisionReport`.

**Рабочая гипотеза:** дашборд повышает наглядность и сокращает время поиска взаимосвязей.
