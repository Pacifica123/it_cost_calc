# ПУАЗ — материал презентации: анализ чувствительности

> Это **сжатая версия** поверх `puaz_sensitivity_academic_context.md`. Формулировки рассчитаны на один основной тезис на слайд, а не на чтение полного текста.

## Слайд 1. Тема

**Интерактивный анализ чувствительности результатов выбора ИТ-решений**

- база — дипломный проект выбора ИТ-конфигураций;
- ПУАЗ-задача — исследовать **устойчивость** итоговой рекомендации;
- результат — сценарный HTML-дашборд + JSON.

**Устно:** первый дашборд объясняет один результат, эта работа исследует, как результат меняется при изменении условий.

---

## Слайд 2. Проблема

**Один Hybrid winner не показывает устойчивость решения**

Нужно ответить:

- сохранится ли лидер при изменении баланса GA/AHP;
- где происходят смены лидера;
- насколько широк интервал устойчивости;
- что изменится при более жёстком TCO-пороге.

`[A2] = чувствительность результата`, `[E] = точка запуска отчёта`.

---

## Слайд 3. Исходные данные и алгоритм

```text
DecisionReport
  ↓
Hybrid rows: GA-score + AHP-score + ranks + Pareto + TCO
  ↓
Hᵢ(λ) = λ·GA_norm + (1−λ)·AHP_norm
  ↓
серия λ-сценариев
  ↓
winner / switch points / stability
```

- `λ=0` → приоритет AHP;
- `λ=0.5` → компромисс;
- `λ=1` → приоритет GA.

**Важно:** GA/AHP заново не запускаются.

---

## Слайд 4. Что рассчитывается

**Показатели устойчивости**

- доля сценариев, где кандидат является лидером;
- устойчивость базового победителя;
- количество смен лидера;
- интервалы лидерства по `λ`;
- число допустимых альтернатив при TCO-пороге.

**Не вероятность:** доля лидерства относится к программно заданной сетке сценариев.

---

## Слайд 5. Интерактивные визуализации

**1. Hybrid-score × λ — line chart**  
Показывает динамику и пересечения альтернатив.

**2. Доля лидерства — horizontal bars**  
Сравнивает устойчивость кандидатов.

**3. TCO × λ — heatmap**  
Показывает области, где сохраняется один победитель.

**4. Таблица сценария**  
Даёт точные score, TCO и Pareto-статус.

---

## Слайд 6. Интерактивность

Пользователь изменяет:

- **ПО / ТО**;
- **λ** — баланс GA ↔ AHP;
- **TCO-порог**.

Все элементы перестраиваются для одного текущего сценария:

```text
параметры → пересчёт → winner → графики → таблица
```

Интерактивность используется как инструмент what-if анализа, а не как оформление.

---

## Слайд 7. Методические границы

**TCO-порог — не новый запуск GA**

```text
экспортированный пул
  ↓
TCO-фильтр
  ↓
Hybrid-пересчёт
```

Модуль:

- не создаёт отсутствующие альтернативы;
- не пересчитывает pairwise AHP;
- не подменяет исходные методы диплома;
- явно показывает неполные данные.

## Слайд 9. Отличие двух разработчиков

| Первая ПУАЗ-работа | Вторая ПУАЗ-работа |
|---|---|
| визуализирует один результат | строит серию сценариев |
| «почему варианты отличаются?» | «насколько устойчив выбор?» |
| TCO × аналитическая поддержка | Hybrid-score × λ |
| фильтры результата | параметры what-if |
| интерпретация | sensitivity analysis |

**Главная фраза:** общий диплом и экспорт, но разные аналитические задачи и программные результаты.

---

## Слайд 10. Вывод

**Разработан сценарный слой анализа устойчивости рекомендации.**

- единичный Hybrid-result преобразуется в серию сценариев;
- визуально выявляются области лидерства и переключения;
- интерактивность позволяет исследовать what-if условия;
- результат остаётся воспроизводимым и не меняет методику GA/AHP.

**Финальный вывод по конкретным альтернативам формулируется только после фактического прогона на утверждённых данных.**
