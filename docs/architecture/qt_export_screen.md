# Qt export screen

Патч `qt-export-screen` переносит корневой раздел `Экспорт` в новый Qt-контур.

Экран сохраняет принцип миграции: один основной сценарий, минимум постоянных
элементов и подробности в раскрываемых блоках. Главный сценарий — выбрать формат
и нажать `Собрать отчёт`. Полный отчёт включает JSON, Markdown, CSV, автономный HTML-дашборд интерпретации и отдельный сценарный HTML/JSON-анализ чувствительности.

## Что умеет экран

- собирает полный DecisionReport в JSON, Markdown и CSV;
- экспортирует отдельный CSV затрат;
- формирует частичные Markdown-фрагменты по затратам и NPV;
- формирует автономный интерактивный HTML-дашборд по уже собранному DecisionReport без повторного запуска аналитических методов;
- формирует отдельный sensitivity/what-if отчёт: пересчитывает прозрачный Hybrid-слой по `λ` и показывает TCO-порог как фильтр уже экспортированного пула;
- показывает краткую сводку данных перед экспортом;
- показывает последние созданные файлы.

## Ограничения этапа

Sensitivity-отчёт работает только по тем Hybrid-данным, которые уже присутствуют в `DecisionReport`.
Изменение `λ` воспроизводит прозрачную формулу Hybrid, но TCO-порог является только post-analysis
фильтром текущего экспортированного пула: он не перезапускает GA/AHP и не создаёт отсутствующие кандидаты.
Частичные режимы экспорта сохраняются для совместимости.
